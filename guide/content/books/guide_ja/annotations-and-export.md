# アノテーションとエクスポート

## アノテーション

**染色体**・**領域**・**移動**と同じ行の**公開ゲノム**で、hg38/GRCh38、hg19/GRCh37、hs1/T2T-CHM13、mm39/GRCm39 の公開遺伝子を選べます。ツールバーの**アノテーション**を押すと、ローカルの GFF3、GTF、BED を直接開けます。両者は別の段に同時表示できます。公開遺伝子には転写産物とエクソンを表示します。**設定 → 公開遺伝子の取得元**で、UCSC（初期値）と Ensembl を切り替えられます。UCSC は hg38・hg19・mm39 に `knownGene`、hs1 に `ncbiRefSeq` を使います。Ensembl は独自の遺伝子モデルを使い、hg19 は GRCh37 専用 API から取得します。このアプリでは Ensembl と hs1 の組み合わせは未対応のため、案内を表示します。hs1 には UCSC を選んでください。デスクトップ表示と SVG の公開注釈見出しに取得元を表示します。インターネット接続が必要で、領域を移動するたびに再取得します。取得に失敗した場合も、ローカル注釈は表示したままです。

公開ゲノムの初期値は「なし」です。**D4 を開く**と両方の注釈選択が解除され、**D4 を追加**では保持されます。D4 からアセンブリは判定できないため、一致する公開ゲノムを選んでください。公開遺伝子では `1` と `chr1` などの一般的な名前を対応付けます。ローカルファイルの染色体名は従来どおり完全一致が必要です。GFF3/GTF では gene、transcript、mRNA、exon を表示します。

通常ファイルとgzipファイルは32 MiB・解析済み10万featureまでメモリに読み込めます。大きいファイルはbgzipで圧縮し、tabixの`.tbi`または`.csi`を付けてください。インデックス付き`.gz`はHTSlib経由で検索します。

## ビンを書き出す

表示中のトラックを選び、**ビンを書き出す**を押します。bedGraphには現在の表示ビンの平均が入ります。塩基ごとの元データではありません。解像度を変える場合は、先に領域とビン数を変更してください。

bedGraphは**0始まり・終点を含まない**区間で、画面は**1始まり・両端を含む**座標です。コメントには元ファイルのパスとトラック名が入るため、共有前に確認してください。入力D4や現在のアノテーションへの上書きはできません。

## SVGを保存する

**ファイル → プロットをSVG画像として保存**で、スクロール外を含む表示中の全トラックとアノテーションを保存します。`.svg`を省略すると自動で追加します。
