# コマンドラインで使う（上級者向け）

ほとんどの研究者はこのページを読まず、デスクトップアプリケーションを使えば十分です。
ここでは、実験室での自動化、共有コンピューター、ローカルブラウザ表示、インストールを
支援するIT担当者向けに説明します。

D4 Plotには2種類のコマンドラインエントリーポイントがあります。

- `d4-plot`はネイティブデスクトップアプリケーションを起動します。
- `d4-plot serve`と`d4-plot-server`は、ネイティブUIなしでローカルのIGV.jsビューアを起動します。

各実行ファイルに`--help`を付けると利用できるオプションを表示します。パスは現在の
ディレクトリからの相対パス、または絶対パスを指定できます。

## デスクトップアプリケーション

1つ以上のD4ファイルを開きます。

```sh
d4-plot sample.d4
d4-plot sample1.d4 sample2.d4
```

最初の形式では指定したファイルを開きます。アプリケーション内の**D4を開く**は現在の
トラックを置き換え、**D4を追加**は現在の表示にトラックを追加します。

1始まり・両端を含む座標で開始領域を指定できます。

```sh
d4-plot --region chr1:1,000,000-2,000,000 sample.d4
```

同じ形式はアプリケーションの領域入力欄でも使用できます。`chr1:100`のような1塩基の
指定や、読み込んだD4に存在する`chr1`のような染色体名も有効です。座標にはカンマを
使用できます。

1回の起動だけ言語を指定するには`--locale`を使います。

```sh
d4-plot --locale ja sample.d4
```

コマンドラインの言語指定は保存済みの設定より優先されます。指定しない場合は、保存済みの
設定、または言語設定が**システムの設定**ならOSの言語を使用します。言語設定と保存場所は
[設定と言語](preferences.md)を参照してください。

## ローカルブラウザビューア

`serve`サブコマンドと単独の`d4-plot-server`実行ファイルは同じオプションを受け付けます。
トークン付きURLを表示し、Ctrl-Cを押すまで配信を続けます。

```sh
d4-plot serve --genome hg38 --open sample.d4
d4-plot-server --genome hg38 --open
```

`--open`を指定すると標準ブラウザを自動で開きます。ブラウザを起動できない場合もサーバーは
停止せず、表示されたURLを手動で開けます。サーバーは`127.0.0.1`だけで待ち受けるため、URLは
同じコンピューターで開いてください。URLにはセッション用トークンが含まれるため、共有しないでください。

### 参照配列の選択

参照配列は次のうち最大1つを指定します。

| オプション | 意味 |
| --- | --- |
| `--genome ID` | `hg38`などIGVの公開プリセットを使用します。 |
| `--reference PATH` | ローカルのFASTAまたはIGV genome JSONを使用します。 |
| `--contigs-only` | D4ファイルの染色体名と長さだけを使用します。 |

ローカルFASTAには対応する`.fai`インデックスが必要です。インデックスがFASTAの隣にない
場合は`--reference-index`で指定します。

```sh
d4-plot-server --reference reference.fa \
  --reference-index indexes/reference.fa.fai sample.d4
```

IGV genome JSONでは、JSONが参照するローカルファイルに実行環境からアクセスできる必要が
あります。JSON参照に`--reference-index`は使用できません。

D4ファイルを指定し、別の参照配列を指定しない場合、ビューアはD4のcontig辞書を
**Contigs only**として使用できます。これは染色体名と長さだけを提供し、塩基配列はありません。
D4ファイルを作成した参照アセンブリを証明するものでもありません。D4ファイルなしで起動する
場合は、`--genome`または`--reference`を指定してください。

公開プリセットでは、ブラウザが設定された公開ホストから参照データを取得します。参照データの
アクセスをローカルに限定する必要がある場合は、ローカルのFASTAとFAIを使用してください。
追加トラックやCRAMへの影響は[IGVとの連携](igv-integration.md)を参照してください。

### サーバーのオプション

| オプション | 意味 |
| --- | --- |
| `--region REGION` | 初期領域。例: `chr1:100-200`。 |
| `--locale LOCALE` | ブラウザビューアの言語です。 |
| `--port PORT` | ループバックポート。`0`なら空きポートを選びます。 |
| `--open` | 起動後にビューアURLを開きます。 |
| `--help` | 使用方法を表示して終了します。 |

FASTA参照と初期領域を指定してローカルビューアを起動する例です。

```sh
d4-plot serve --reference reference.fa --region chr1:100-200 --locale ja --open
```

オプションの後にD4のパスを指定します。D4のパスを省略する場合も、`--genome`または
`--reference`が必要です。`--genome`、`--reference`、`--contigs-only`は同時に指定できず、
`--reference-index`には`--reference`が必要です。

Windowsで表示されたURLをコピーする場合は、ターミナルから`d4-plot-server`を実行してください。
macOSのアプリケーションバンドルでは、単独実行ファイルは
`d4-plot.app/Contents/MacOS/d4-plot-server`にあります。
