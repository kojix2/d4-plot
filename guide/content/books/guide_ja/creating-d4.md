# D4ファイルの作成

**D4を作成**を選び、次を指定します。

- BAI/CSI付きの座標ソート済みBAM、またはCRAI付きのCRAM
- CRAMの場合は対応するFASTAと`.fai`
- `.d4`で終わる新しい出力先

比較するトラックやアノテーションと同じ参照アセンブリを使ってください。変換ではアセンブリの不一致を修正できません。

![BAMと出力先を指定したD4作成画面](../../screenshots/ja/create-d4.png)

画像のBAMは生成した例です。実際の作業にはインデックス付きファイルを指定してください。

## カバレッジモード

| モード | 計数範囲 |
| --- | --- |
| **標準** | アライン済み塩基。CIGARギャップを除き、重複するmateは1回数えます。 |
| **高速** | ギャップを含むリード全体。重複するmateは2回数えます。 |
| **フラグメント** | insertを含むproper pairのテンプレート区間。 |

## 設定

**基本設定**でファイルとモードを選びます。**詳細設定**では次を指定できます。

- 最小MAPQ
- SAMの包含・除外フラグ（初期値の`0x704`ではunmapped、secondary、QC-failed、duplicateを除外。supplementaryは除外しません）
- リードグループとテンプレート長の絶対値範囲
- BAM/CRAM展開スレッド数（初期値2）

**D4を作成**で変換を始めます。処理中もビューアは使えます。完了後に**ビューに追加**を押すと表示できます。押さなくてもファイルは保存されます。

D4 Plotはsecondary-frameとsumのインデックスを作り、ファイルを検証してから公開します。既存ファイルは上書きしません。公開前の中止や失敗では一時結果を削除します。
