# まずここから

## ファイルを用意する

D4ファイルを使うか、インデックス付きの座標ソート済みBAM/CRAMから作成します。CRAMには対応するFASTAと`.fai`も必要です。詳しくは[D4ファイルの作成](creating-d4.md)を参照してください。

ファイルを比較する前に参照アセンブリと処理条件を確認してください。D4にはアセンブリ識別子がありません。

## 開いて確認する

1. [GitHub Releases](https://github.com/kojix2/d4-plot/releases)からパッケージをインストールします。
2. **D4を開く**でファイルを選びます。BAM/CRAMを変換する場合は**D4を作成**を選び、完了後に**ビューに追加**を押します。
3. `chr1:100000-200000`のような領域を入力して**移動**を押します。`chr1`だけなら染色体全体を表示します。
4. タイトルまたは一覧からトラックを選びます。高さを比較するときは**Y軸を共有**を有効にします。
5. シグナルにポインタを置いてビン平均を確認します。狭いピークは拡大してください。

## 移動と出力

**戻る**、**進む**、拡大縮小、**全染色体**を使います。ドラッグで移動、Shift+ドラッグまたは右ドラッグで範囲選択します。プロットにフォーカスがあるときは左右キーで移動、`+`/`-`で拡大縮小、Homeで全染色体、Escで読み込みやドラッグを中止できます。

- **D4を追加**: トラックを追加
- **アノテーション**: ローカルの GFF3、GTF、BED を開く。公開遺伝子は移動行の先頭にある**公開ゲノム**で選択
- **ビンを書き出す**: 選択トラックのビン平均をbedGraphに保存
- **プロットをSVG画像として保存**: スクロール外を含む表示中のトラックとアノテーションを保存

尺度と移動方法は[トラックの表示](viewing-tracks.md)、形式と座標は[アノテーションとエクスポート](annotations-and-export.md)を参照してください。

## 表示がおかしいとき

| 症状 | 確認すること |
| --- | --- |
| D4を開けない | ファイルが存在し、読み取り可能で、書き込みが完了しているか。 |
| BAM/CRAMを変換できない | 座標順、インデックス、CRAM用の参照FASTA/FAI。 |
| トラックが合わない | アセンブリと染色体名。`chr1`と`1`は異なります。 |
| ピークが平らに見える | 拡大するか、**設定**でビン数を増やします。 |
| 高さが比較しにくい | **Y軸を共有**または固定Y軸を使います。 |
