# IGVとの連携

| 目的 | 操作 |
| --- | --- |
| 現在の領域をIGV Desktopへ送る | **IGV → IGV Desktopで領域を表示** |
| D4とBAM/CRAM、VCF、BED、GTF、BigWigを一緒に表示 | **IGV → ゲノムブラウザ (IGV.js) を開く…** |
| デスクトップ画面なしでブラウザ版を使う | [`d4-plot serve`または`d4-plot-server`](command-line.md) |

## IGV Desktop

1. IGV Desktopを起動し、D4と同じ参照アセンブリを選びます。
2. D4 Plotで領域を表示します。
3. **IGV → IGV Desktopで領域を表示**を選びます。

D4 Plotは`127.0.0.1:60151`へ領域だけを送ります。IGV Desktopの起動、アセンブリ変更、トラック追加は行いません。D4のメタデータではアセンブリを確認できないため、両方のアプリで確認してください。

## IGV.jsブラウザ

**IGV → ゲノムブラウザ (IGV.js) を開く…**を選びます。D4がなくても起動できます。参照配列を選び、**D4 tracks**でトラックを選択して**Apply selection**を押します。最初の12トラックは自動選択されます。すべて外すこともできます。

**Add track**でローカルファイルまたはURLを追加します。形式に必要なインデックスも指定してください。形式を判定できない場合はFormatまたはTrack typeを指定します。追加したローカルファイルは、参照・D4選択の変更やページ再読み込み後に再選択が必要です。URLにはブラウザからアクセスできる必要があり、別オリジンにはCORS、インデックス付きデータにはHTTP Rangeが必要です。

| 参照配列 | 動作 |
| --- | --- |
| **Contigs only** | D4がある場合の初期値。染色体名と長さのみで、塩基配列や検証済みアセンブリはありません。 |
| `hg38`、`hg19`、`hs1`、`mm39` | 公開プリセット。ブラウザがIGV/UCSCのホストから参照を取得し、閲覧した参照と概略領域が伝わる可能性があります。 |
| ローカルFASTA/FAIまたはIGV genome JSON | [サーバーCLI](command-line.md)で指定し、参照へのアクセスをローカルに限定できます。 |

D4がない場合は`hg38`で始まります。公開プリセットでは`hg38`、`hg19`、`mm39`にGENCODE、`hs1`にNCBI RefSeqの遺伝子トラックを追加します。Contigs onlyとローカル参照では追加しません。追加トラックのアセンブリと染色体名は参照に合わせてください。CRAMには塩基配列が必要です。

D4は1要求につき最大1024ビンです。利用できるsum indexがあればビン平均は正確です。ない場合の広域表示は標本平均になり、狭いピークを見落とすことがあります。拡大するかsum indexを追加してください。

サーバーは`127.0.0.1`だけで待ち受けます。URLにはセッショントークンがあるため公開しないでください。ブラウザの**View locus in IGV Desktop**は、検証済みの染色体辞書を持つ参照と単一領域がある場合に使えます。送信するのは領域だけです。

## 困ったときは

| 症状 | 確認すること |
| --- | --- |
| IGV Desktopへ送れない | 起動中で、`127.0.0.1:60151`の外部制御を受け付けているか。 |
| D4が表示されない | **D4 tracks**の選択、参照との染色体名・長さの一致。 |
| 追加トラックが表示されない | 形式、インデックス、アセンブリ。URLではCORS/HTTP Rangeも確認。 |
| 公開プリセットが読み込めない | ネットワーク接続。必要ならローカルFASTA/FAIを使用。 |
| 古いブラウザタブが使えない | D4 Plotから開き直します。 |
