# IGVとの連携

D4 Plotは、現在の領域をIGV Desktopへ送るか、D4とほかのゲノムトラックをローカルの
IGV.jsビューアで表示できます。両者は別の機能です。

| 操作 | できること | 事前条件 |
| --- | --- | --- |
| **IGV → IGV Desktop で領域を表示** | D4 Plotで表示中の領域へ、起動済みIGV Desktopを移動 | IGV Desktopが`127.0.0.1:60151`で外部制御を受け付けていること |
| **IGV → ゲノムブラウザ (IGV.js) を開く…** | D4と追加のゲノムトラックをブラウザで表示 | なし。D4がない場合はhg38で起動します。 |
| `d4-plot serve` / `d4-plot-server` | ネイティブGUIなしで同じIGV.jsビューアを提供 | D4ファイル、`--genome`、`--reference`のいずれかを指定 |

## IGV Desktopに領域を送る

1. IGV Desktopを起動し、比較するD4と同じ参照アセンブリを選びます。
2. D4 PlotでD4トラックと目的の領域を表示します。
3. **IGV → IGV Desktop で領域を表示**を選びます。

- D4 Plotは`/goto`コマンドで**領域だけ**を送ります。IGV Desktopの起動、ゲノムの変更、
  D4トラックの読み込みは行いません。
- 接続はバックグラウンドで行われます。成功はステータスに、失敗はエラーダイアログに表示されます。
- D4ファイルのメタデータだけでは参照アセンブリを確定できません。染色体名と長さが一致しても、
  同じアセンブリとは限らないため、両方のアプリケーションで確認してください。

## IGV.jsでD4とほかのトラックを表示する

1. D4 Plotで**IGV → ゲノムブラウザ (IGV.js) を開く…**を選びます。D4ファイルを
   開いていなくても、ブラウザでほかのトラックを追加できます。
2. 開いたブラウザで参照配列を選びます。必要に応じて**D4 tracks**でトラックを選択し、
   **Apply selection**を押します。D4をすべて外して、追加トラックだけ表示することもできます。
3. **Add track**からローカルファイルまたはデータURLを追加できます。IGV.jsが扱うBAM、CRAM、
   VCF、BED、GTF、GFF3、BigWigなどをD4と同じ領域に表示できます。必要なインデックスも指定します。
   拡張子から形式を判定できないときは、FormatやTrack typeを指定してください。
4. ブラウザ内で領域を移動・拡大縮小します。D4は1回の要求につき最大1024ビンで表示します。
   利用可能なD4のsum indexがあれば、染色体全体でも正確な平均値を表示します。利用可能なsum indexがない広域では
   読み取り量を制限した標本平均を表示する場合があります。正確な値には拡大表示するか、D4にsum indexを追加してください。

| 項目 | 動作 |
| --- | --- |
| 初期表示 | D4 Plotで表示中の領域を使用します。選択した参照配列に合わない場合は、有効な領域へ切り替えます。 |
| トラック | 最初の12トラックを自動選択します。残りは**D4 tracks**から追加できます。 |
| 追加トラック | **Add track**からローカルファイルまたはURLを指定します。大きなBAM、CRAM、圧縮VCF、アノテーションには、利用できる場合は対応するインデックスを指定してください。 |
| 参照配列 | D4を開いている場合は**Contigs only**、ない場合は`hg38`で始まります。ブラウザでは`hg38`、`hg19`、`hs1`、`mm39`に切り替えられます。 |
| 遺伝子アノテーション | 公開プリセットでは、対応する遺伝子トラックを自動表示します。`hg38`、`hg19`、`mm39`はGENCODE、`hs1`はNCBI RefSeqです。**Contigs only**とローカル参照には自動追加しません。 |
| D4値 | 1回の要求につき最大1024ビンです。利用可能なsum indexがない広域では標本平均を使う場合があり、狭いピークを見落とすことがあります。正確な値には拡大してください。 |
| 接続 | サーバーは`127.0.0.1`にだけ待ち受け、URLにはセッション用トークンが含まれます。URLは公開しないでください。 |

参照配列を選ぶ際は、次の違いに注意してください。

| 選択 | 配列データ | 注意点 |
| --- | --- | --- |
| **Contigs only** | D4の染色体名と長さのみ | 塩基配列はありません。D4由来の辞書が存在しても、実際の参照アセンブリが確認できたことにはなりません。 |
| 公開プリセット | IGV/UCSCの公開ホストから取得 | インターネット接続が必要です。閲覧した参照と概略領域が参照ホストへ伝わり得ます。 |
| ローカルFASTA / IGV genome JSON | ローカルのFASTAとFAIを使用 | 後述のCLIで指定します。参照データの取得をローカルに限定できます。 |

追加するトラックの染色体名とアセンブリは、選択した参照配列に合わせてください。CRAMには
塩基配列を含む参照を選びます。ローカルファイルはブラウザが直接読み込むため、参照配列や
D4トラックの切り替え、ページ再読み込み後は選び直します。URLのデータ元にはブラウザから
アクセスできる必要があり、別オリジンの場合はCORS、インデックス付きファイルには
HTTP Rangeへの対応が必要です。

ブラウザの**View locus in IGV Desktop**は、辞書のある参照と単一領域が表示されている
ときだけ使用できます。公開プリセットには検証済みの辞書がないため、このボタンは無効です。
送るのは領域だけです。IGV Desktop側のアセンブリは自動変更されません。

## GUIを起動せずに使う

`d4-plot serve`と`d4-plot-server`は同じオプションを受け付けます。

```sh
d4-plot serve --genome hg38 --open sample.d4
d4-plot-server --genome hg38 --open
d4-plot-server --reference reference.fa --reference-index reference.fa.fai sample.d4
d4-plot-server --contigs-only sample.d4
```

| オプション | 用途 |
| --- | --- |
| `--genome ID` | 公開プリセットを選択します。 |
| `--reference PATH` | ローカルFASTAまたはIGV genome JSONを選択します。FASTAには既存のFAIが必要です。 |
| `--reference-index PATH` | FASTAのFAIが標準のパスにない場合に指定します。 |
| `--contigs-only` | D4の染色体名と長さだけを使用します。D4があり、ほかの参照を指定しない場合もこのモードです。 |
| `--region REGION` | 初期領域を指定します。例: `chr1:100-200`。 |
| `--open` | ブラウザを自動で開きます。失敗してもサーバーは起動したままです。 |
| `--port PORT` | 待ち受けポートを指定します。初期値の`0`は空きポートを選びます。 |

- `--genome`、`--reference`、`--contigs-only`は同時に指定できません。
- D4ファイルなしで起動する場合は`--genome`か`--reference`を指定してください。
- 起動時に表示されるURLを**同じコンピューター**のブラウザで開いてください。
- 終了するにはターミナルでCtrl-Cを押します。

## 困ったときは

| 状況 | 確認すること |
| --- | --- |
| IGV Desktopへ接続できない | IGV Desktopが起動し、`127.0.0.1:60151`で外部制御を受け付けているか確認します。D4 PlotはIGV Desktopを自動起動しません。 |
| ブラウザでトラックが表示されない | **D4 tracks**で選択されているか、参照配列とD4の染色体名・長さが一致するか確認します。 |
| 追加したファイルが表示されない | ファイル形式、インデックス、参照配列の染色体名を確認します。URLの場合はCORSとHTTP Rangeへの対応も確認します。 |
| 公開プリセットが読み込めない | インターネット接続を確認するか、ローカルFASTA/FAIで起動します。 |
| 以前のブラウザタブが使えない | D4 Plotのトラック変更後は、**IGV → IGV.js で D4 トラックを開く…**から開き直します。 |
| `HTTP::Client::Response#body_io cannot be nil` | 旧ビルドのIGV Desktop応答処理が原因です。修正を含む版に更新するか、ソースビルドなら`shards build d4-plot`を再実行してください。 |
